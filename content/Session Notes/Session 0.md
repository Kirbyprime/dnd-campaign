## Session Overview

Discuss expectations, ideas and house rules. 

## Key Learnings

- Campaign centered in the Forgotten Realms
- Campaign is SFW. e.g. no rape, etc.
- Total Reset of the world. Previous campaign never happened.
- Party is "evil". The overall party goals are evil.
- Only using core materials for character creation. 2024/2014 Player's Handbook.
- If there is any rules conflict, 2024 is truth.
- Characters start at level 3.
- Characters level via experience up to level 5. Will reassess at that time.
- Characters are strangers to each other but have the same patron.
